# Bottom navigation mockups (#92)

`bottom-navigation.png` (rendered from `bottom-navigation.html`) shows the five-tab bottom bar
and the simpler Home that #92 builds, with the store showcase data (STORE-SHOT-006).

**What the mockups fix:** which tabs exist and their order and labels, what each screen holds
and where (the ring, Stretch now, the Today list with upcoming reminders first and today's past
ones greyed beneath, Skip/Resume today on the Today heading, banners on Home only, "Skip other
days" on Schedules, "My stretches" on Settings), and the no-goals and skipped-day states.

**What they do not fix:** exact icons, colours, type, spacing and the figure drawing. The build
uses the app's theme (`StretchTheme`, including dynamic colour), Material icons for the tabs,
and the launcher icon's side-bend figure in the ring, as the widget does (WIDGET-004). The
"Weekend" schedule is illustrative and not part of the showcase fixture.
