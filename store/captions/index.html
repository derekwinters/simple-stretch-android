Store screenshot captions

The caption on each Google Play phone screenshot, one entry per shot ID of the store listing specification, and last the text of the feature graphic. This file is the only place the text lives: the screenshot and feature graphic tests read it, and a caption that does not fit (at most 3 headline lines and 2 supporting lines, as rendered) fails that test (STORE-SHOT-012, STORE-SHOT-014, STORE-GRAPHIC-004).

Each entry is a ## heading with the shot ID, then a Headline: line and a Supporting: line. Changing a caption changes its image, which is then re-recorded in the same pull request (the record-store-screenshots label, or ./gradlew recordRoborazziDebug locally; STORE-SHOT-009).

The feature graphic's entry, STORE-GRAPHIC-003, is a pair of claims: each of its two lines ends with the requirement IDs it rests on as an HTML comment, e.g. <!-- SCHED-001 -->, as in the listing text. The comment is not drawn; the test fails if a line has none or cites an ID the specification does not define or has retired (STORE-GRAPHIC-003). Only claim what the cited requirements say.
